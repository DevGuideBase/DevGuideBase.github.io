Common release and cd pipelines mistakes mistakes in Security Reviews

Before you implement anything above, make sure you are not stepping on one of these well-known rakes:
  • Hard-coding secrets directly into YAML instead of linking a variable group backed by Key Vault.
  • Running every stage on every branch, which burns parallel-job minutes for nothing.
  • Skipping pipeline caching, so dependency restore downloads the same packages thousands of times.
  • Using the same service connection for dev and production deployments.
  • Ignoring pipeline permissions, letting any contributor redeploy protected environments.
If you recognise your own setup in three or more of these, stop adding features and spend a day on remediation first. The fixes are usually small; the incidents they prevent are not.
