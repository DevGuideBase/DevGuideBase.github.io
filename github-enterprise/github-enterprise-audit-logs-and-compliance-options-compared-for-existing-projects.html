Common mistakes and how to avoid them

The pattern in most audit logs and compliance options incidents is boringly consistent. Watch for these:

  • Not streaming audit logs to SIEM, so investigations lack history.
  • Mixing personal and service accounts in the same IdP lifecycle.
  • Upgrading Enterprise Server without a tested restore drill.
  • Granting enterprise-wide PAT scopes when repo-level tokens suffice.
  • Configuring branch protections per repo instead of enforced rulesets.

Every item on that list has the same root cause: something that was true when it was written stopped being true later. Re-check these assumptions whenever the surrounding system changes, not only when audit logs and compliance options itself breaks.
