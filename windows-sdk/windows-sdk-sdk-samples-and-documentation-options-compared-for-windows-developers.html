Common mistakes and how to avoid them

Before you implement anything above, make sure you are not stepping on one of these well-known rakes:

  • Mismatched WindowsTargetPlatformVersion across projects in one solution.
  • Building on agents missing the exact SDK/workload version.
  • Hard-coding paths to Kits\10\Include with pinned minor versions.
  • Mixing Debug runtime libs into Release links (LNK2038 grief).
  • Forgetting arm64 configurations until the port lands.

None of these are exotic. They are the quiet defaults that look fine in review and fail at 3 a.m. Closing even two of them puts your sdk samples and documentation options setup ahead of most teams we audit.
